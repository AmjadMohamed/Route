# HTML Course Task - World Wonders Webpage

## Overview
This task involves creating a simple webpage using pure HTML to display information about famous world wonders. The design follows a table-based layout, with images and descriptions structured in rows and columns.

## Learning Objectives
- Understand and implement semantic HTML elements.
- Use tables to organize content effectively.
- Incorporate images with appropriate alt text.
- Apply inline styles for basic styling.
- Ensure readability and accessibility of content.
